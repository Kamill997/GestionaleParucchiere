# Frontend — Gestionale Salone di Parrucchiere

Vite + React 19 + TypeScript. Vedi `../docs/01-frontend.md` per stack e
struttura cartelle completa, `../README.md` per l'avvio del progetto intero.

## Script

- `npm run dev` — dev server (http://localhost:5173)
- `npm run build` — type-check + build produzione
- `npm run lint` — ESLint
- `npm run format` / `npm run format:check` — Prettier
- `npm run test` — Vitest
