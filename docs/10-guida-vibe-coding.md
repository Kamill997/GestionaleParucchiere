# Guida al Vibe Coding con questi File

## Cos'è, in pratica

"Vibe coding" qui significa: invece di scrivere il codice riga per riga, si guida un'IA con istruzioni via via più specifiche, verificando il risultato a ogni passo. I file `00`-`09` di questa raccolta servono esattamente a questo.

## Preparazione

1. Crea la cartella del progetto e mettici dentro tutti questi file `.md` in una sottocartella, es. `docs/`
2. Inizializza un repository Git fin da subito
3. Tieni la cartella `docs/` aggiornata mano a mano che prendi decisioni definitive diverse da quanto scritto qui

## Strumento consigliato

Uno strumento agentico come **Claude Code** è più adatto di una semplice chat per questo tipo di lavoro (codice reale, su più file, in un repository).

## La regola più importante: procedere a fasi, non tutto insieme

Meglio seguire le fasi già definite in `05-passaggi-esecutivi.md`, una alla volta, verificando che ognuna funzioni davvero prima di passare alla successiva.

## Buone pratiche mentre si procede

- **Un modulo per volta**
- **Verifica prima di andare avanti**
- **Commit frequenti**
- **Chiedi anche i test**
- **In caso di errore, incolla l'errore vero**
- **Rileggi il codice generato**

## Checklist prima di iniziare

- [ ] Tutti i file `.md` copiati in `docs/` dentro il repository del progetto
- [ ] Repository Git inizializzato
- [ ] Strumento di vibe coding scelto e configurato
- [ ] Prima richiesta pronta: setup iniziale, non l'intero progetto
- [ ] Un'idea chiara delle fasi da seguire una alla volta
